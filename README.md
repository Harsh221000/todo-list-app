# My Todo List - Task Management Application

![Todo List](https://img.shields.io/badge/Todo%20List-App-667eea)

A modern, feature-rich to-do list application with local storage functionality. Stay organized and productive with this beautiful task management tool.

## ✨ Features

### Core Functionality
- ✅ **Add Tasks** - Quickly add new tasks with custom priority levels
- 🎯 **Priority Levels** - Set tasks as Low, Medium, or High priority
- ✔️ **Mark Complete** - Check off tasks as you complete them
- ✏️ **Edit Tasks** - Modify existing tasks and update their priority
- 🗑️ **Delete Tasks** - Remove tasks you no longer need
- 💾 **Local Storage** - All tasks are automatically saved to your browser

### Filtering & Organization
- 🔍 **Filter by Status** - View All, Active, or Completed tasks
- ⭐ **High Priority Filter** - Focus on urgent tasks
- 🔄 **Sort by Priority** - Organize tasks by importance
- 📊 **Real-time Stats** - Track total, active, completed tasks and progress

### Advanced Features
- 📥 **Export Tasks** - Download your tasks as CSV file
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- 📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- 🔔 **Toast Notifications** - Get feedback for every action
- ⌨️ **Keyboard Support** - Press Enter to add tasks

## 🎨 Design Features

- **Gradient Background** - Beautiful purple gradient theme
- **Color-Coded Priority** - Red (High), Orange (Medium), Green (Low)
- **Smooth Animations** - Slide-in effects and hover transitions
- **Interactive Icons** - Font Awesome icons throughout
- **Modal Editor** - Edit tasks in a dedicated modal window
- **Statistics Dashboard** - View progress at a glance

## 🚀 How to Use

1. **Open the Application** - Open `index.html` in your web browser

2. **Add a Task**
   - Type your task in the input field
   - Select priority (Low, Medium, High)
   - Click "Add Task" or press Enter

3. **Manage Tasks**
   - Check the checkbox to mark as complete
   - Click the edit icon to modify a task
   - Click the trash icon to delete a task

4. **Filter Tasks**
   - Click filter buttons to view specific task types
   - Use High Priority filter to focus on urgent items

5. **Organize**
   - Click "Sort by Priority" to reorder tasks
   - Clear completed tasks with "Clear Completed" button

6. **Export**
   - Click "Export Tasks" to download as CSV file
   - Perfect for backup or sharing

## 💾 Local Storage

All your tasks are automatically saved to your browser's local storage. This means:
- Tasks persist even after closing the browser
- No server required
- Complete privacy - data stays on your device
- Works offline

## 📊 Statistics Dashboard

The app displays real-time statistics:
- **Total Tasks** - Count of all tasks
- **Active** - Number of incomplete tasks
- **Completed** - Number of finished tasks
- **Progress** - Percentage of completed tasks

## 🎯 Priority System

- **High Priority** 🔴 - Urgent tasks (red)

- **Low Priority** 🟢 - Less urgent (green)
